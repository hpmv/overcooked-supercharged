## Native r2 result and r3 integration

The native r2 primitive succeeded in the same X session. `artifacts/framework-migration/native-x/body-module-r2-empty-reset.json` shows the empty proxy's COM becoming `(0,0,0)` and tensor becoming `(0,1,0)` immediately after clearing `isKinematic`, before either reset method. This isolates the stale mass state to the kinematic empty-body condition in the observed case; it is not evidence that a broad numeric override is necessary.

External r3 adds that transition to actual restoration only for a native ObjectContainer whose saved/current body is kinematic, saved/current velocities are zero, saved/current collider sets are empty, and scalar mass already equals its target. It clears kinematic, runs the native resets, and restores the original flag in `finally`. It uses no numeric mass-property assignment in this path. The usual exact captured mass, topology, motion and pose checks remain mandatory. Nonempty-body restoration is unchanged.
