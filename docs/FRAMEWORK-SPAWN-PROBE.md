# Bounded native Egg spawn/deletion probe

`scripts/framework_spawn_probe.py` is an operator-run authoring experiment. It has
not yet established native dynamic rewind parity. It makes no connection when
imported or tested offline.

```powershell
C:/Python312/python.exe scripts/framework_spawn_probe.py `
  --trace <owned-headless-exchange.jsonl> --out <new-output-directory> `
  --bridge-port 17636 --controller-port 17637 --maximum-frames 300
```

The operator must provide the currently owned native process and matching trace.
The script verifies windowed Carnival 3-4, DLC8, four local chefs, native Egg crate
65's exact spawn metadata, chef104 in its reachable pantry, and an empty fixed
baseline. It warms up for 30 observed frames, then performs:

1. Ordinary typed approach, six-frame settlement and native Egg pickup.
2. Authoring rollback, requiring exact root **and** physical-container deletion,
   followed by a strict comparison with the observed fixed baseline.
3. Repetition of every originally emitted four-chef input, followed by recording
   export, a second proven deletion, and replay of that recording.

Each advancing leg has a total 300-frame limit including two neutral release
frames. Success requires the actual new raw Egg, its reciprocal chef attachment,
its observed `[65,n]` path and one exact native physical container. A completed
input graph cannot establish pickup by itself. Unrelated native food and the
score/delivery ledger must remain unchanged. Failure stops subsequent input
legs and requests a neutral pause before closing both connections.

The named `live-native-logical-path-v1` comparison retains exact live entity,
native composition/progress, physical pose/velocity/sleep/settings and private
clock values. Dynamic root IDs and a container ID are mapped only through the
observed logical path and shared native `bodyInstanceId`; numerical adjacency is
never evidence of ownership. Fixed identities remain exact. Raw receipts and
raw-ID differences are saved separately, with no tolerance or quaternion
canonicalization.

Headless `registry` and `initialRegistry` retain historical registrations. Only
root/container IDs already proven deleted by a native transaction may be omitted
from the logical registry projection; they must also be absent from live mapped
entities, native food and native bodies. The raw layout report is preserved. Its
specific extra-collider warning is accepted only for this exact Egg/container
profile or those proven retired IDs; all 122 fixed-layout checks remain required.

The result pins source hashes, full receipt/output hashes and exact retained byte
windows of the operator's trace. Comparison covers endpoints and every accepted
input, **not** every intermediate native state. Recreating a saved dynamic target
is explicitly untested by this first probe: a separately validated native
consumption route is required before adding that leg. No delivery score, search
quality or fresh-start qualification follows from this mechanism test.
