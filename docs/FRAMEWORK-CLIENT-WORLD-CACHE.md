`framework/modules/world-sync-cache/NativeClientWorldSnapshot.cs` extends the existing new-snapshot-only server and scheduler sidecar. It copies the client parent reference/ID/bool, server position, received-state flag, and bounded pause bookkeeping for each original fixed PhysicalAttachment. A nonzero parent ID pins its exact registered owner even when the native cached parent reference is null. This null state is legitimate: installed `StartSynchronising` sets `m_Parent=null`, then may record a registered parent ID without resolving the cached reference. Restoration preserves the observed null; it does not invent a resolved parent.

Targets with pending resume data, a paused client synchronizer, nonfinite server position, unknown parent incarnation, or stateful interpolation are rejected. Only a null Lerper or the exact native `EmptyLerp` on the same object is accepted. Existing server settled-state, fixed scheduler membership and native exact pose guards remain. All reference checks occur before core mutation and again before cache writes. After the core's attachment/body restoration, the sidecar restores the recorded cache fields and verifies exact readback. `lastRestore.clientsBefore` and `clientsAfter` retain the actual observed transition.

This extension does not set Transform/Rigidbody poses, call parenting callbacks, reorder/suppress native events, or change scheduler delays, native time or phase counters. Native transport sequence and packet timestamp state is outside this bounded sidecar because the live network transport is not rewound. Unsupported interpolation or pending timer states remain explicit failures.
